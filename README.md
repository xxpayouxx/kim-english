# KIM English V0.3

Compagne conversationnelle d'apprentissage de l'anglais, conçue d'abord pour Safari sur iPhone.

## V0.3
- conversation FR/EN progressive
- réponses libres
- synthèse vocale de Kim
- saisie vocale quand disponible, avec repli sur la dictée iOS
- indices et traduction
- détection simple de difficultés
- mémoire locale via localStorage
- révisions
- XP, niveaux, streak et quêtes
- bilan de séance
- PWA installable

Cette version fonctionne sans serveur et sans API payante. Le prochain jalon est d'améliorer le moteur adaptatif et l'analyse linguistique tout en conservant un mode gratuit.
